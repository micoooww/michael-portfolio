Liwanag Cafe's Restaurant

Web-Based Restaurant and E-Commerce System

Project Overview

Liwanag Cafe's Restaurant is a web-based e-commerce concept designed to manage restaurant products, users, and online orders. The system provides a computerized way of organizing restaurant information and transactions.

Purpose

The system was developed to provide a convenient way of managing restaurant products and customer orders. It helps organize product information and provides a simple interface for managing online transactions.

Key Features

  • Product Management
  • User Management
  • Online Order Management
  • Database Management
  • CRUD Operations
  • Record Searching and Retrieval

Technologies Used

PHP MySQL HTML CSS JavaScript Database

My Role

I contributed to the project documentation by researching, writing and organizing the project content, and documenting the system's features and development process.

What I Learned

Through this project, I learned how to develop a web-based restaurant system and gained experience in database management, CRUD operations, and web development.
